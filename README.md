# stackworks-site

The public pages for StackWorks (the game lives in `jkramp/stackworks`), served by GitHub Pages at https://jkramp.github.io/stackworks-site/.

- `privacy.md` is the privacy policy linked from the Play listing. Edit it, then run `npm install` once, then `npm run build` to regenerate `privacy/index.html`, and commit both.
- `index.html` is a minimal landing page.
